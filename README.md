# 전세 나침반

현대백화점 근무지(청주·울산·대구·대전) 기준으로 전세 후보 단지 1~5순위를 보여 주고,
국토교통부 아파트 전월세 실거래가 API로 예산 이하 전세 계약을 실시간 조회하는 단일 페이지 앱입니다.

| 지역 | 근무지 | 전세 예산 |
|---|---|---|
| 청주 | 커넥트현대 청주 (흥덕구 복대동) | 3억 이하 |
| 울산 | 현대백화점 울산점 (남구 삼산동) | 3.9억 이하 |
| 대구 | 현대백화점 대구점 (중구 계산동) | 4.7억 이하 |
| 대전 | 현대프리미엄아울렛 대전점 (유성구 용산동) | 4.2억 이하 |

## 실행

```bash
node server.mjs   # http://localhost:8787
```

1. [공공데이터포털](https://www.data.go.kr/data/15126474/openapi.do)에서 `국토교통부_아파트 전월세 실거래가 자료` 활용신청
2. 발급된 **Decoding 키**를 앱의 인증키 칸에 입력
3. 브라우저에서 직접 호출이 막히면 프록시 주소에 `http://localhost:8787/api` 입력

추천 단지의 예상 전세가는 참고 범위이며, 실거래 조회 결과가 카드 게이지에 함께 표시됩니다.
